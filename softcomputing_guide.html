EX 01

Perceptron for AND Gate

Perceptron ▼
🍎 Real-Life Analogy
🚦 Imagine a strict security gate that opens only when BOTH guards nod yes. If even one guard says no — the gate stays shut. That's AND.
📋 Program Flow (Step by Step)
1
Setup: Define all 4 input combinations: [0,0], [0,1], [1,0], [1,1]. Set target outputs y = [0,0,0,1] (only last row gives 1).
2
Initialize: Weights = [0.0, 0.0], Bias = 0.0. Learning rate = 0.1. Think of weights as how much we "trust" each input.
3
Training Loop (10 times): For each input row → calculate weighted sum → pass through step function → compare with target → calculate error → update weights & bias.
4
Update Rule: new_weight = old_weight + 0.1 × error × input. If the guess was correct, error=0, nothing changes. If wrong, weights adjust.
5
Testing: After 10 epochs, use final weights to predict all 4 rows. Print result.
🔄 What Happens with Different Inputs
InputWhat the program doesOutput
[0, 0]Weighted sum = 0+0+bias ≈ small negative. Step fn → 00 ✅
[0, 1]Only second weight matters. Sum still below threshold0 ✅
[1, 0]Only first weight matters. Sum still below threshold0 ✅
[1, 1]Both weights contribute. Sum crosses threshold1 ✅
Change y to [1,1,1,1]Every combo has target=1. Weights grow large to always fireAlways 1
🎓 Say to Examiner"The perceptron learns by adjusting weights based on the error between predicted and actual output. For AND gate, only when both inputs are 1 does the weighted sum cross the threshold."

EX 04

Perceptron for XOR Gate

Multi-Layer ▼
🍎 Real-Life Analogy
💡 A light that turns ON only when exactly one switch is flipped. Flip both or neither → light stays off. This is like a "disagreement detector."
📋 Why XOR is Special
⚠️ XOR is NOT linearly separable!
You CANNOT draw one straight line to separate the 1s from 0s in XOR. That's why a single perceptron FAILS for XOR. We need 2 layers (hidden + output).
📋 Program Flow (Step by Step)
1
Hidden Layer (2 neurons): Each neuron looks at the input differently. Neuron 1 acts like "at least one is 1" (OR-like). Neuron 2 acts like "both are 1" (AND-like).
2
For each input, compute h1 and h2 using fixed weights. These are hand-crafted weights (not learned in this program).
3
Output Layer: Takes [h1, h2] and computes: h1 AND (NOT h2) = XOR. Uses step function on the final result.
🔄 What Happens with Different Inputs
Inputh1h2Final Output
[0, 0]000 ✅
[0, 1]101 ✅
[1, 0]101 ✅
[1, 1]110 ✅
🎓 Say to Examiner"XOR cannot be solved by a single-layer perceptron because it's not linearly separable. A 2-layer network with a hidden layer decomposes XOR into OR and AND sub-problems."

Hebb Network

Unsupervised ▼
🍎 Real-Life Analogy
🧠 "Neurons that fire together, wire together." Like when you always hear thunder after lightning — your brain automatically links the two. No teacher needed — just repetition.
📋 Program Flow (Step by Step)
1
Input: X uses +1 and -1 (bipolar). y is the desired output (+1 or -1). This is bipolar instead of binary (0,1).
2
Learning (one pass only): For each row, weight += X[i] × y[i]. No training loop needed — Hebb adds up all contributions directly.
3
No error correction: Unlike perceptron, Hebb never checks if it was right or wrong. It just blindly adds.
4
Test: net = dot(X[i], weights) + bias. If net > 0 → output 1, else -1.
🔄 What Happens with Different Inputs
Input (bipolar)What happensOutput
[1, 1] → target 1Both positive, product positive → weights increase+1
[1, -1] → target -1Input mixed, target neg → weights pulled negative-1
Change to binary (0,1)Rows with 0 contribute nothing. Less learning signalMay not converge well
Add conflicting patternsWeights get pulled in opposite directions → confusionIncorrect outputs
🎓 Say to Examiner"Hebb's rule is unsupervised — there is no error calculation. Weights are updated as the outer product of input and output, accumulating associations over all training patterns."
EX 07

Hopfield Network

Associative Memory ▼
🍎 Real-Life Analogy
📷 Like recognizing a blurry, half-torn photo of your friend. Your brain fills in the missing parts from memory. Hopfield networks do the same — given a noisy pattern, they recall the original stored one.
📋 Program Flow (Step by Step)
1
Store patterns: Two patterns are stored in a weight matrix using: W += outer(p, p). This is the "memory".
2
Remove self-connections: fill_diagonal(W, 0). A neuron shouldn't influence itself.
3
Give noisy test input: [1, -1, -1, -1] (slightly corrupted from stored pattern [1,-1,1,-1]).
4
Iterative update: Each neuron votes based on its neighbors. After 5 rounds, the pattern stabilizes (converges) to the nearest stored memory.
🔄 What Happens with Different Inputs
Test InputWhat HappensOutput
[1,-1,1,-1] (exact)Already matches stored pattern → no change needed[1,-1,1,-1] ✅
[1,-1,-1,-1] (1 bit flip)Network corrects flipped bit through iterations[1,-1,1,-1] ✅
[1,1,1,1] (heavy noise)Too far from any stored pattern → may give wrong resultUnpredictable ⚠️
Store 3 patterns (too many)Capacity exceeded → spurious (fake) memories appearWrong recall ⚠️
🎓 Say to Examiner"Hopfield network is a recurrent network that stores patterns as stable states. It retrieves the closest stored pattern from a noisy input by minimizing an energy function."

Auto Associative Memory

Memory ▼
🍎 Real-Life Analogy
🪞 Like a mirror that shows you your perfect, clean face even if you walk in with mud on it. Input = dirty pattern, Output = clean original.
📋 Program Flow (Step by Step)
1
Store patterns: 5-element bipolar patterns. W += outer(p, p). Diagonal set to 0.
2
Give noisy input: [1,-1,1,1,1] — 4th element is flipped (original was -1).
3
Iterate 10 times: Each neuron recalculates using W[i] · state. Gradually corrects to stored pattern.
4
Result: Noisy input → recalled clean output (same type, hence "auto").

Hetero Associative Memory

Memory ▼
🍎 Real-Life Analogy
📖 Like a two-language dictionary. You input a word in Tamil → get back the English meaning. Input and output are completely different things.
📋 Program Flow (Step by Step)
1
Define pairs: X (3-element input patterns) and Y (4-element output patterns). These are the "dictionary entries."
2
Build weight matrix W: W (4×3 matrix) = sum of outer(Y[i], X[i]). Shape is different from auto-associative because input/output sizes differ.
3
Recall: Given test_input (3-element), compute W · test_input. Apply sign function to get the recalled Y pattern.
🔄 What Happens with Different Inputs
Input PatternBehaviorOutput
[1,-1,1] (exact)Direct lookup → perfect match[1,1,-1,-1] ✅
[-1,1,-1] (exact)Second stored pair recalled perfectly[-1,-1,1,1] ✅
[1,1,1] (unseen)Closest match wins → may give partial recallApproximate
[0,0,0]No signal → all zeros → sign(0) edge caseUnpredictable
🎓 Say to Examiner"Hetero associative memory learns a mapping between two different pattern spaces. The weight matrix W = Σ outer(Y, X) stores all input-output pairs."
EX 10

ADALINE

Gradient Learning ▼
🍎 Real-Life Analogy
🎯 Imagine adjusting the aim of a dart. A perceptron only cares if you hit or missed. ADALINE also cares by HOW MUCH you missed — and corrects proportionally. More precise!
📋 Program Flow (Step by Step)
1
Key difference from Perceptron: ADALINE uses the raw linear output (no step function) to calculate error during training. It minimizes MSE (mean square error).
2
Forward pass: y_pred = X · w + b. No step function during training — raw decimal values.
3
Update: w += lr × X.T · (y - y_pred). All inputs updated at once (batch learning). More stable than perceptron.
4
Plot: Decision boundary line drawn. Points colored by class label.
🔄 What Happens with Different Inputs
ChangeEffect
Increase epochs (20→100)Weights converge more accurately, better boundary
Increase learning rate (0.1→0.9)Overshoots, weights oscillate, may not converge
Change to OR gate (y=[0,1,1,1])Line shifts position — different boundary for OR
Use XOR dataNo single line can separate — ADALINE will fail
🎓 Say to Examiner"ADALINE uses the Widrow-Hoff (LMS) learning rule. Unlike the perceptron, it uses the continuous output — not the thresholded output — to calculate the error during weight updates."

MADALINE

Multi-ADALINE ▼
🍎 Real-Life Analogy
👥 Like having two expert judges, each viewing the problem from a different angle, and a final judge who combines their opinions. More powerful than one judge alone.
📋 Program Flow (Step by Step)
1
XOR problem: y = [-1,1,1,-1]. Can't solve with single ADALINE. Need 2 hidden neurons.
2
Hidden layer: 2 neurons with random initial weights W. Each computes sign(X·W[i] + b[i]).
3
Output layer: Takes [h1, h2] and computes final output using weights V.
4
Only output layer is updated: If output is wrong, V and bo are adjusted. Hidden weights W are FIXED. This is the MADALINE rule (MRI).
🔄 What Happens with Different Inputs
ChangeEffect
Change target to AND [-1,-1,-1,1]Network solves it easily — simpler problem
Increase epochs (100→500)More training → better chance of convergence for XOR
Change random seedDifferent initial W → may converge or fail (randomness)
Add 3rd hidden neuronMore capacity → solves complex problems better
🎓 Say to Examiner"MADALINE uses multiple ADALINEs in the hidden layer. Using the MRI rule, only the output layer weights are updated when the output is incorrect."

Bidirectional Associative Memory (BAM)

Memory ▼
🍎 Real-Life Analogy
🔄 Like a two-way street. If you see a face (X), you remember the name (Y). If you hear the name (Y), you picture the face (X). Works both directions.
📋 Program Flow (Step by Step)
1
Store pairs: X (3-element) paired with Y (2-element). W = sum of outer(X[i], Y[i]). Shape: 3×2.
2
Forward (X→Y): y_out = sign(test_x · W). Multiply X by W to get Y.
3
Backward (Y→X): x_out = sign(y_out · W.T). Multiply Y by W-transpose to recover X.
4
Verify: Recalled X should match original test_x. This proves the bidirectional nature.
🔄 What Happens with Different Inputs
InputBehaviorOutput
[1,-1,1] (stored pattern)Exact match → W gives perfect Y; W.T gives back X[1,-1] then [1,-1,1] ✅
[-1,1,-1] (second pattern)Retrieves its associated Y pattern[-1,1] ✅
[1,1,-1] (unseen)Closest pattern wins → approximate recallNearest stored
🎓 Say to Examiner"BAM is a two-layer recurrent network. W = Σ outer(X,Y) stores associations. Forward pass X→Y uses W, backward pass Y→X uses W transpose."

EX 14

Back Propagation Network

Deep Learning ▼
🍎 Real-Life Analogy
🎓 Like a student who gets exam results, figures out exactly where they went wrong in each step, and corrects each step working backwards from the final mistake.
📋 Program Flow (Step by Step)
1
Setup: XOR dataset. Two weight matrices W1 (input→hidden, 2×2) and W2 (hidden→output, 2×1). Both initialized randomly.
2
Forward pass: h = sigmoid(X · W1), o = sigmoid(h · W2). Sigmoid squishes output between 0 and 1 smoothly.
3
Calculate error: error = y - o. How far off is the output?
4
Backward pass: d_o = error × sigmoid'(o). Then d_h = (d_o · W2.T) × sigmoid'(h). Error travels backwards through layers.
5
Update weights: W2 += lr × h.T · d_o. W1 += lr × X.T · d_h. Repeat 5000 times.
🔄 What Happens with Different Inputs
ChangeEffect
Reduce epochs (5000→100)Under-trained → wrong predictions for XOR
Change lr=0.5 → lr=2.0Overshoots gradients → weights explode, NaN errors
Add 3rd hidden neuron (2→3)More capacity → faster convergence
Change XOR to AND dataConverges much faster since AND is simpler
Different random W1, W2May reach different final weights but same correct output
🎓 Say to Examiner"Backpropagation calculates the gradient of the error with respect to each weight using the chain rule. It propagates the error backward from output to input layer to update all weights."
EX 15

Adaptive Resonance Theory (ART)

Unsupervised ▼
🍎 Real-Life Analogy
🗂️ Like a student creating new folders for each type of subject. If a new topic is similar enough to an existing folder — add it there. If it's too different — make a new folder. And old folders are never erased!
📋 Program Flow (Step by Step)
1
Vigilance = 0.6: This is the "strictness" threshold. Higher = more clusters. Lower = fewer, larger clusters.
2
For each new input: Check similarity with each existing cluster weight using: match = sum(min(x, w)) / sum(x).
3
If match ≥ vigilance: Assign input to that cluster. Update cluster weight: w = min(x, w).
4
If no match found: Create a brand new cluster for this input. No forgetting of old clusters!
🔄 What Happens with Different Inputs
ChangeEffect
vigilance = 0.9 (high)Very strict matching → more clusters created
vigilance = 0.2 (low)Everything grouped together → fewer clusters
Add very different pattern [1,1,0,0]New cluster created (doesn't match any existing)
Add identical pattern twiceGoes to same cluster, weight unchanged (already matched)
🎓 Say to Examiner"ART solves the stability-plasticity dilemma. The vigilance parameter controls cluster granularity. New patterns that don't match existing clusters create new ones, preserving old memories."

Membership Value Assignment Methods

Fuzzy Logic ▼
🍎 Real-Life Analogy
🌡️ "Is 28°C HOT?" In regular logic: yes or no. In fuzzy logic: "28°C is 0.7 hot and 0.3 warm." The membership function tells you the degree of truth.
📋 Program Flow — 4 Membership Shapes
🔺
Triangular: Rises linearly to 1 at peak, falls back to 0. Simple tent shape. Used when there's one clear "center" value.
🔷
Trapezoidal: Like triangular but flat on top — a range of values all get membership = 1. Used when a range is acceptable.
🔔
Gaussian: Bell curve. Smooth, gradual transitions. Very natural-looking. Used in temperature, pressure controls.
📈
Sigmoid: S-curve. Gradually rises from 0 to 1. Used when there's a gradual transition (e.g., "becoming hot").
🔄 What Happens with Different Inputs
x valueTriangular(x)Gaussian(x)Sigmoid(x)
x = 0 (peak)1.0 (maximum)1.0 (maximum)0.5 (midpoint)
x = 3 (edge)0.0 (boundary)~0.01 (near 0)~0.98 (near 1)
x = -50.0 (outside)~0.00003~0.08
Change peak b=5→b=0Triangle shifts leftGaussian shifts leftSigmoid shifts
🎓 Say to Examiner"Membership functions define how each input value maps to a degree of membership between 0 and 1. Different shapes suit different real-world scenarios — triangular for sharp transitions, Gaussian for natural gradations."

Counter Propagation Network

Competitive ▼
🍎 Real-Life Analogy
🏆 Imagine a competition where employees bid on tasks. The most suitable employee (winner) takes the task and learns from it. The winner adjusts to become even better for similar future tasks.
📋 Program Flow (Step by Step)
1
Kohonen (competitive) layer: 2 neurons with random weights k. For each input, find the closest neuron using Euclidean distance.
2
Winner takes all: winner = argmin(distance). Only the winner neuron gets to update.
3
Update Kohonen weights: k[winner] += lr × (x - k[winner]). Moves the winner closer to the current input.
4
Update Grossberg (output) weights: g[winner] += lr × (t - g[winner]). Moves output weight toward the target value.
🔄 What Happens with Different Inputs
ChangeEffect
epochs 500 → 100Less training → inaccurate outputs
learning_rate 0.1 → 0.5Faster learning but may overshoot
3 Kohonen neurons (k=3)More clusters → finer mapping but slower
Different random seedDifferent winner assignments → may or may not converge
🎓 Say to Examiner"Counter propagation uses competitive learning in the Kohonen layer to find the best matching neuron, then the Grossberg layer adapts the output toward the target."

Classical Set vs Fuzzy Set Relations

Fuzzy Logic ▼
🍎 Real-Life Analogy
🎨 Classical set: "You are either IN the tall people group or NOT." Fuzzy set: "You are 0.8 tall and 0.3 medium." Real life rarely has sharp boundaries.
📋 Program Flow (Step by Step)
1
Classical Cartesian Product: All possible pairs from A×B. {(1,2),(1,3),(1,4),(2,2),...}. Every combo listed.
2
Classical Relation: Only pairs where a == b. {(2,2),(3,3)} — strict equality.
3
Fuzzy Sets defined: fuzzy_A = {1:0.2, 2:0.5, 3:0.8}. Each element has a degree of membership.
4
Fuzzy Relation: For each pair (a,b), degree = min(membership_A, membership_B). Captures partial association.
🔄 What Happens with Different Inputs
ChangeEffect
A=[1,2], B=[3,4] (no overlap)Classical relation = [] (empty — no equal pairs)
fuzzy_A = {1:1.0, 2:1.0}All membership = 1. Fuzzy relation becomes same as classical
Use max instead of min for fuzzyChanges to fuzzy union relation (different semantics)
🎓 Say to Examiner"Classical sets use crisp boundaries — membership is 0 or 1. Fuzzy sets allow partial membership. The fuzzy relation between two sets uses the minimum of their membership values."

Triangular Membership Function

Fuzzy Logic ▼
🍎 Real-Life Analogy
⛰️ Like defining "medium height" — heights below 5 ft are 0% medium, 5.5 ft is 100% medium, and 6 ft is again 0% medium. A mountain peak of membership.
📋 Program Flow (Step by Step)
1
Parameters: a=2 (start), b=5 (peak), c=8 (end). The triangle lives between 2 and 8, peaking at 5.
2
Left slope: For x between a and b: membership = (x-a)/(b-a). Rises from 0 to 1.
3

Fuzzy Travelling Salesman Problem

Fuzzy Logic ▼
🍎 Real-Life Analogy
🚗 A delivery driver visiting 4 cities wants the shortest total route. But the distances aren't exact — traffic varies, so each distance is a range like "10 to 14 km." Fuzzy TSP handles this uncertainty.
📋 Program Flow (Step by Step)
1
Fuzzy distances: Each road is a triangular fuzzy number (min, mid, max). E.g., city 0→1: (10,12,14) means "somewhere between 10 and 14."
2
Defuzzification: Convert each fuzzy distance to one crisp number: (min+mid+max)/3. E.g., (10+12+14)/3 = 12.
3
Try all permutations: 3! = 6 possible routes (excluding start city 0). Calculate total cost for each.
4
Pick best: Route with minimum total defuzzified cost wins. Print it.

Add city 4 (more cities)4! = 24 permutations → same logic, more routes checked

EX 21

Lambda Cuts in Defuzzification

Fuzzy Logic ▼
🍎 Real-Life Analogy
✂️ Imagine a triangular mountain. Lambda cut is like taking a horizontal slice at a certain height (e.g., 60% up). The width of that slice gives you a range. The middle of that range is your crisp answer.
📋 Program Flow (Step by Step)
1
Fuzzy number (2, 5, 8): Triangle starts at 2, peaks at 5, ends at 8.
2
Lambda = 0.6: We want the portion where membership ≥ 0.6. Cut the triangle at height 0.6.
3
Left boundary: left = a + λ(b-a) = 2 + 0.6×(5-2) = 2 + 1.8 = 3.8.
4
Right boundary: right = c - λ(c-b) = 8 - 0.6×(8-5) = 8 - 1.8 = 6.2.
5
Defuzzify: crisp = (3.8 + 6.2) / 2 = 5.0. The answer! Turns out it's always the peak for symmetric triangles.
🔄 What Happens with Different Inputs
ChangeLeftRightCrisp Value
λ = 0.02.08.05.0 (full range)
λ = 1.05.05.05.0 (just the peak)
λ = 0.53.56.55.0
Asymmetric: (2,4,8)3.26.44.8 (shifted left)
🎓 Say to Examiner"Alpha-cut (lambda-cut) slices a fuzzy set horizontally at level λ, producing a crisp interval. Defuzzification takes the mean of this interval. For symmetric triangles, the result always equals the peak value."
